# ml/

The active NeuroGolf ML work is `ml/ngs/`: Neural-Guided ONNX program Search.

Start here:

- `ml/ngs/README.md`
- `python -m ml.ngs.run selftest`
- `python -m ml.ngs.backends` if you need to inspect local GPU/ONNX environments

The previous top-level `ml/README.md` described an older Orbit Wars / Arc A770
environment setup and did not describe this repository. Agent F moved the useful
hardware notes into `_cleanup/proposals-F.md` so they can be copied back to the
right project or archive without shadowing the current NGS documentation.
