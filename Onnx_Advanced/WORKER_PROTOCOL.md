## Gates (ALL before staging a primary)
1. `ng_gate visible --task N --cand X.onnx` — must be 100%. **One visible miss = certain hidden 0 (traps §VISIBLE-FAIL AXIOM)** — abandon the candidate.
2. `ng_gate truth --task N --n 8000` — capped heavy truth corpus. If LIVE itself is <100% (run the same truth cap on the LIVE extract FIRST — traps §CLASS-CHECK), the task is ambiguous-class: byte-equal-vs-LIVE replaces 100%-truth as the gold gate. Do not use raw `--full`/n=200000 for routine heavy verification. `<99%` truth AND not byte-equal = a learning artifact, never "best" (traps §14e).
3. `ng_gate ab --task N --n 8000` — capped byte-equal-vs-LIVE = gold ship class. Divergences → traps §DUAL-TRUTH attribution (run truth on BOTH; `ab_divs == LIVE_misses − cand_misses` ⇒ more-correct-than-LIVE, shippable).
4. Cost: `tools/_score_v2.py` — **STATIC graphs price EXACTLY; any dynamic shape/dummy-branch/optional-input makes local cost FICTION (78× seen)** — build static, stage a boring-static sibling beside any exotic rung (traps §GRADER-GAP).
5. **REAL-INPUT PROFILE (mandatory, the task225 reprice)**: run the candidate over the REAL officials with ORT profiling (`tools/agent_helpers/profile_real_cost.py`) and compute the `max(static, runtime)` per tensor — the result IS the credited cost. Record `profile_cost` in the manifest next to `score_v2` cost; any gap >5% = the rung is a credit-probe, not an exact ship (one free own-stack probe decides — traps §GRADER-GAP).

**Gate hygiene (resource safety)**: cheapest-first (visible → profile → capped `truth`/`ab --n` → heavy `truth`/`ab --n 8000` ONLY after a visible pass + strict cost win), always in the FOREGROUND — never `--new-window`/background/detached/`--no-throttle`. The HandOff runner reaps a timed-out worker by killing its whole process tree; a detached gate escapes that and burns CPU with a dead parent. Heavy truth/ab/battery gates are capped across all agents (throttle.py, `NEUROGOLF_HEAVY_GATE_K`=5) so parallel heavy gates stay bounded — a gate that pauses briefly is waiting its throttle turn, not hung; `--no-throttle` bypasses this, so don't use it. Record a dead route (visible-zero family, proven floor) in one line under `Task_by_Task/taskNNN/hard_records/` so the next batch doesn't re-run it.
