## Doctrine blocks — axiom-grade rules (condensed 2026-06-10; verbatim originals in `traps_appendix.md`)

> **§VISIBLE-FAIL AXIOM — one visible miss = certain 0.** Officials ⊆ hidden and per-task scoring is all-or-nothing; NO generator/synth coverage overrides it (a 200k-synth-passing probe still landed its exact fail value). Five independent proofs: task193 8-rung ladder (×8 exact fail values), task363 probes, task145, task086 v17/v20 (both to the cent). Fire sub-100%-visible rungs ONLY as deliberate distribution probes (keeps-highest makes them free) — never as candidates. **Sibling discipline:** byte-equal primary ⇒ a worse-cost sibling can never contribute, skip it; non-byte-equal primary ⇒ ONE different-architecture sibling is a cheap hedge.

> **§14e LEARNING-ARTIFACT RULE — run `ng_gate truth --full` BEFORE staging.** <99% truth AND not byte-equal-to-a-correct-LIVE = learning artifact, never "best"; visible-pass is necessary, not sufficient. Deterministic visible-pass + truth-fail = hidden 0; ambiguous tasks go through §CLASS-CHECK. **Task023 cliff:** the hidden-credit threshold was between 92.86% and 95.65%; higher truth can still lose if the cost/credit tradeoff is worse. **Signature:** N≈266 statistic-hash tables or NN/MLP/CAE distillations. **Scars:** task077 −13.13 · task396 −13.40 · task370 −13.04 · task157 0.00 · task233+192 recurrence (261/2000 truth = 13%).

> **§PUBLIC-NEG — confirmed public-negative FORMULATIONS (the retired `dont_probe` list, 2026-06-20).** These specific graphs passed local visible/truth/arc-gen gates yet DROPPED public score on a Kaggle own-stack probe — local gates do NOT catch them, only the probe does (a §14e/§VISIBLE-FAIL hidden-bad realization). **They are FORMULATION traps, NOT task blocks:** the task stays improvable with a *different* formulation — task177's `konbu_cost_probe` dropped public, but its byte-equal `coloridx_booltail` formulation probe-VERIFIED **+0.554** (2026-06-20); task303 `lane_nomix` (220, byte-equal) and task351 `v9_sepgrid` (1358, byte-equal) likewise probed clean. **Rule: don't re-walk the named graph; DO probe-to-expose a genuinely different one (esp. byte-equal-to-LIVE).** Confirmed public-negative graphs: **task009** papaya10_orange10 `block_grid_line_fill` · **task153** date9_cherry9 `afr5044_cheaper` · **task175** elderberry10_banana10 `afr5044_static` · **task177** xigua9_tangerine9 `konbu_cost_probe`/`kernel-output-konbu17-lb5126` · **task187** cherry10_banana10 `afr5501_partition` (raw dynamic-shape cost probe) · **task224** watermelon9_tangerine9 `afr5653_cost_probe`. (The blocklist that froze these *tasks* was retired and `captain_ctl.load_dont_probe()` neutered — permanent task-blocking wrongly stalls improvable tasks. Full record: `Agenters/Submit_Captain/dont_probe.RETIRED_2026-06-20.json`.)

> **§CLASS-CHECK protocol — classify any <100%-truth candidate first.** Run `ng_gate truth --task N --cand <LIVE-extract> --n 5000`. **LIVE < 100% => AMBIGUOUS/FILTERED-CLEAN:** byte-equal-to-LIVE is the gold gate; same-noise-band bets can ship, but visible must still be 100%. >=99% truth is not safe if it diverges from LIVE (task219 99.045% lost; byte-equal 7094 shave is safe). **LIVE == 100% => DETERMINISTIC:** misses are bugs; park them. Roster — ambiguous: 209, 064, 018, 187, 157, 079, 205, 048; deterministic: 025, 145.

> **§DUAL-TRUTH — an A/B divergence is not a verdict; attribute it.** Run `ng_gate truth` on BOTH candidate AND LIVE over the same window: the divergence can be a LIVE-bug the candidate FIXES (task279, task377 class — shippable at exact prediction). **Arithmetic shortcut:** if `ab_divergences == LIVE_GT_misses − candidate_GT_misses` and candidate misses ⊆ LIVE misses, every divergence is more-correct-than-LIVE ⇒ fire (task187: 21 = 29 − 8). Padding-count masks and single-axis floods can diverge from LIVE in opposite directions; same-corpus attribution distinguishes dirty churn from a cheaper superset (task064/task243). Worker ab windows under-sample — captains re-run ab deeper before firing.

> **§GRADER-GAP — the cost oracle (consolidates the 2026-06-04…10 stack; mechanism: techniques §39 MECHANISM).** `calculate_memory` = **max(static, runtime-on-REAL-inputs)** per tensor. STATIC graph ⇒ local == Kaggle EXACT, no probe needed. DYNAMIC graph ⇒ local cost is FICTION (measured 78× task094, 37× task398, 18× task360 — 358→6,442, caught pre-staging by gate-5 — 2.9× task225, 2.5× task132, 1.4× task014) and repricing converges to the true-trace cost regardless of the local number. **The verdict is binary and ONE free own-stack probe decides it** (task091 dynamic genuinely traced cheap and WON +0.22; task132/029 lost) — gate-5 (profile≠static) flags the RISK, the probe reads the verdict, and the boring-static sibling is the floor either way; never ship a dynamic unprobed, never agonize. **CRASH CLASS:** dynamic graphs can die outright at buffer-reuse on REAL inputs after scoring fine on dummy shapes (task061 v11/v12, task354 v11) — run the actual officials end-to-end before staging anything dynamic. Exotic graphs (dummy-branch / optional-input / bool-Pad collapses): treat local cost as a LOWER BOUND and ship the static sibling in the same round. **TOOLING DEFAULT (2026-06-19): `profile_real_cost.py` defaults to `--arcgen 0` (4 dummy inputs), which UNDER-measures dynamic-Slice/crop graphs — pass `--arcgen 262` to size the true max-crop; a single-channel U8 crop canvas beats both F32 variants.**

> **§FREE-OUTPUT SAFETY BATTERY.** **(a) Boundary leak:** positive off-center taps in an output-writing Conv can fire outside the active grid; gate with border-stress or corpus margin. For border/interior detectors on variable active regions, Conv bias is mandatory to suppress padding-neighbor positives (task171). **(b) Active-mask:** variable-size Equal-tail rewrites must sentinel inactive cells (`Where(act_b, values, 10u8)`) and price that into the #81 crossover. **(c) Clip-dup phantom:** shrinking a read plane changes overflow semantics; re-prove every Clip target or mask it (task209). **(d) Decode positivity:** NeuroGolf decodes per-channel `>0`, not argmax; out-of-bounds cells must emit 0, and one scalar descriptor cannot encode >2 mutually-exclusive classes under positivity (task127/task357). **(e) F16 inf carriers:** structural edits to inf-carrying free-output graphs need real-input nan/inf scans; truth% can hide nan in ignored cells (task138).

> **§FAMILY-LABEL MISNOMER — the family/transformations label is a HINT; ARC-GEN is the rule.** Decode the generator first; if label and generator conflict, generator wins. Measured misnomer rates: 3/20 batch-16 and 11/40 big-fish. Examples: task359 "Symmetry Completion" = DENOISING; task266 "Filling Regions" = fixed diagonal shift; task038 "Cropping" = count-blue-boxes; task367 "fill rectangles" has connector false-walls that defeat global/separable rectangle fill. Tell: the label-implied technique fails visible while a different decode passes.

> **§GENERATOR-INVARIANT vs OFFICIALS-QUIRK.** ARC-GEN `generate()` constraint loops may only run on `width is None`; official pairs are injected with fixed values and can violate generated invariants. Decode the generator for hidden, but gate officials and add explicit repairs for their enumerable quirks (task077). task133 officials violate the top-left-pivot invariant and force a sparse guard; task340 fixed max-window slices include actual border cells for smaller grids, so the `interior_color` mask is load-bearing.

> **§K2 ACT-NOW PAIR (ORT 1.24.4 source-read).** (a) `TopK(sorted=0)` order is UNSTABLE (ORT skips the final sort after `nth_element`) — only the selected SET is contractual; always set `sorted=1` (ties → lower index). (b) Integer arithmetic is native C++: `Mod(fmod=0)` sign = divisor; integer `Div` truncates toward ZERO (not floor); integer `Pow` casts `std::pow` output. Full compendium: `ort_reality.md` K2 section.

> **§INPUT-DTYPE-LOCK.** The gate harness feeds `x.astype(np.float32)` for EVERY gate; non-F32 model inputs are untestable/unshippable locally. Reductions/Slice/Gather/Conv reads straight off input stay F32; casting the whole frame down costs 9,000 U8 or 18,000 F16 before any savings. Confirmed floors: task255 one-channel read = 3,600B, task370 20x20 F32 slice before U8 QLinearConv, task173 dual F32 Conv reads, task198 Slice+Cast double-charge. Use #98-style Conv read/fuse only when it avoids materializing the F32 plane.

> **§TRAP-ESCAPE PLAYBOOK — when a synth-passing UNLOCK ships 0 LB.** The fix is rule re-derivation, never more synth or more compression. **Descriptor test:** implementation nouns in your build comments (hash, signature, table, pair-pack, sparse-stamp, scorer-aware) = you're in the trap; algorithmic nouns (count, reflect, extend, fill, select) = out. Steps: (1) stop compressing the wrong rule; (2) re-derive from visible pairs with fresh eyes (discard your own numpy reference); (3) map to the ARC-AGI-2 axes (K-Arc2 cross-ref note 02); (4) verify the NEW rule produces structurally DIFFERENT outputs from the trap candidate on 3–5 differentiating inputs — if it can't, you're still in the trap; (5) compress within the new family only; synth ≥98% suffices for an asymmetric unlock. Escapes: task366 v72 +13.50, task255 v12 +14.90. If a re-derived 266/266 rule STILL ships 0: differentiating-input synthesis, then per-axis classification; a 4-way-dead architecture (task233 precedent) means pivot the rule hypothesis entirely.

> **§27 LOOKUP-FAMILY DETECTION (refined) + THE UNLOCK PATTERN.** Detection signals, in order of weight: (1) **table size vs the 266 visible pairs** — N<50 structured tables = SAFE rule primitives; N≈200–300 keyed by input-statistic hash = hidden-bad; (2) **adversarial %** — <1% = memorization, >30% with small tables = ship; (3) init NAMES prove nothing (task370 shipped +2.52 with `hk_*` names). Trained-NN distillations belong to the same zero-weight class. **cherry13b Identity stub = the universal zero-weight disambiguator** (one free submit; same score back ⇒ LIVE contributes 0). **MAJOR OVERTURN (2026-05-23):** "lookup scores same as LIVE" ⇒ LIVE also memorizes — latent weight may exist; 13 confirmed structural unlocks (066 +15.62, 277 +15.27, 076 +15.00, 101 +15.19, 118 +15.51, 158 +14.56, 367 +14.24, 096 +15.83, 363 +14.31, 133 +11.57, 324 +13.90, 182 +14.62, 219 +15.94). Zero-weight tasks score **0 actual** on hidden (not the 1.0 formula floor); an asymmetric ship captures the candidate's FULL cost-points.

> **§23a HIDDEN-FRAGILE tasks (logged LB-scar) — ship byte-equal to the PROVEN anchor.** A task that already burned you (task382: −12.29 scar) gets the byte-equal compression of a Kaggle-validated version (v22 ≡ v9 anchor), not a sub-floor gamble — downside is the task's full ~15 pts on a known-dangerous task. Non-fragile tasks may take ONE non-byte-equal bet IF a byte-equal floor ships last in the same spread (task234 pattern). Fragile tasks don't get the bet.

> **§25 CALIBRATION REGIMES — predicted LB = `Σ log_e(orig/new)` × regime multiplier.** Single-task wildcard **1.0×** (~21 ships within ±0.05) · small stack 2–7 **~1.0× additive** · ~30-task mid stack **~0.84×** (megastack33) · 100+ megastack **~0.48×** · cascade unlock = step-function exception (one confirmed: task110 +12.73; follow-on reverts with undershoot) · zero-public-weight **0.00 regardless of cost** · hidden-cost-decoupled partial/zero (task284 full, task234 ~22%). Never apply a positive multiplier to zero-weight family tasks. Details: `cost_floor_reference.md` calibration section.
