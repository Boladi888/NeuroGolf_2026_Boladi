## Pattern

For any **select-or-keep rule** — `out = select(mask, replacement, input)` where most cells
pass through — lift the final `Where` to full canvas scale and make it the output node:

```
Where(cond [1,1,30,30] BOOL, X [1,10,30,1] (or other broadcastable), input) -> output
```

Both full-canvas 10-channel tensors are then FREE: `Y = input` (graph input, skipped) and
the result (named `output`, skipped — #67). You pay only for `cond` and `X`.

This inverts the ubiquitous **crop → process-in-one-hot → Pad-back** shape (LIVE task312 and
the 97 scan-flagged `Pad→output` tasks): crop-scale processing charges the 10-channel crop
(5,760 B F32 / 2,880 B F16 at 12×12) AND the pre-pad result (2,880 B). At canvas scale both
endpoints are free; only the small mask/replacement operands are charged. Pad the *cond*
(BOOL, 900 B at 30×30), never the data.

## Reusable micro-facts (param encoding)

- **Slice, axes-omitted form**: a 3-axis crop on rank-4 costs starts[4]+ends[4] = 8 params,
  beating the axes-form 3+3+3 = 9. (Axes-form only wins when cropping ≤2 axes.)
- **Gather beats Slice for single-index extraction**: `Gather(input, [k], axis=a)` = 1 param
  (axis is an attribute); `Slice` needs starts+ends+axes = 3. Keep indices shape `[1]` (not
  scalar `[]`) — scalar drops the rank and right-aligned broadcasting then mis-addresses.
- Where requires X/Y dtype match: Y=input pins X to F32 — don't chase F16/u8 on the X branch
  (casting input costs ≥9,000 B).

## When it applies

- Rule is a sparse/conditional overwrite of the input (color mapping, cell repair,
  mask-gated recolor, object overwrite) — anything expressible as one final select.
- The mask is genuinely 2-D (else cheaper rank-1 cond shapes apply) and the replacement is
  broadcast-expressible ([1,10,30,1] row-source / [1,10,1,30] col-source / [1,10,1,1]
  constant color...).
- Check the 97-task `Pad→output` scan list (#67 SPREAD TARGET, `scan_freeout_candidates.py`)
  for tasks whose pre-pad tensor is a Where/select result — each is a candidate for this
  exact inversion.
