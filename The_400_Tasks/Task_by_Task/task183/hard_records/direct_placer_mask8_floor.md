# task183 hard record - direct placer mask8 deletion

- live bar used: 561 profile/static cost, manifest source via `python tools/ng_current_bar.py --task 183 --json`, live SHA-256 `44f7d89716a510f217456179b3b608b46b753983308aa495c9a065898bb0df57`.
- reviewer-locked route: replace the live upstream carrier around `mask8_f` / `mask8` / `q_features` with a direct placer/output formulation that deletes the F32 cyan slice family.
- attempt 1, QLinear direct placer: rejected before build. `QLinearConv` needs INT8/UINT8 input, but the harness feeds F32 and the only cyan source is the F32 graph input. `Cast(input -> U8)` creates a 9,000 B full-frame tensor, already above the 561 bar. `Slice(ch8) -> Cast(U8/BOOL)` keeps `mask8_f` 144 B plus a 36 B narrow copy, so it does not delete the F32 family and collapses back to the live formulation.
- attempt 2, direct placer output: rejected by price. A one-shot Conv/placer that sees both the shifted cyan cell and the variable absolute corner cells must cover relative offsets from `-5` to `+9` on both axes, i.e. a dense 15x15 kernel. Dense Conv/QLinearConv params are `10 output channels * 10 input channels * 15 * 15 = 22,500`, before bias or any U8 cast, far above 561. The sparse-looking weights do not help because params count dense initializer elements.
- separable/free-output fallback price: arbitrary cyan scatter on the 6x6 compact grid needs one term per cell (`T=36`) by the task183 rank gate. Even the small-grid selector set `K[36,10] + R[36,6] + C[36,6]` costs 792 params, above 561 before corner reads or black-channel handling; full 30-wide selectors cost 2,520 params.
- exact failed gate: pre-build dtype/price proof. No reviewer-ready ONNX was produced; no visible/profile/full gates were run for this dead route.
- remaining hypothesis: only a new op pattern that reads the F32 input and emits the final one-hot output without dense spatial kernels, without QLinearConv's U8 input requirement, and without per-cell selector params could delete `mask8_f`; #84/#85/#137 do not supply that for task183.
