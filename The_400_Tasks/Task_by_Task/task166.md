## Rule

**Cross-product occupancy fill, fill color 2** (decoded 2026-06-06, verified vs ARC-GEN 200k truth).
Inputs contain shapes of a non-bg color (color 8 in all officials; detector is color-agnostic) on bg 0.
Every **bg cell whose row contains a non-bg cell AND whose column contains a non-bg cell** becomes color 2; all other cells pass through. Empty grid → identity.

Note the semantics precisely: it is the **cross product (occupied rows) × (occupied cols)**, not a literal [rmin..rmax]×[cmin..cmax] bbox. For a single 8-connected shape these coincide (a connected shape's row set and col set are intervals), and ARC-GEN truth at 200k/200k confirms cross-product is the generator's rule. LIVE implements the same cross-product (`Mul(row_has, col_has)`).

Key correctness lemma (kills the 1-ch0 trap *and* the separate bg path): every cross-product cell lies in an occupied row and an occupied column, hence inside the active grid → there, `bg ⇔ ¬nonbg`. No active-cell guard needed.

## Algorithm sketch

```python
nb   = (grid != 0)                                  # nonbg, any color
cond = nb.any(1, keepdims=True) & nb.any(0, keepdims=True) & ~nb
out  = np.where(cond, 2, grid)
```
