## Rule

Decode a hidden 3x3 rare-color drawing from a translated, thickened lattice:

1. Find the dominant non-zero color.
2. Rare cells are non-zero cells whose color is not dominant.
3. Take the first four rows containing any rare cell and the first four columns containing any rare cell.
4. Sample the 4x4 color-index patch at those row/column intersections.
5. For each 3x3 output position, inspect the corresponding 2x2 window in that 4x4 patch. If all four values are the same rare color, emit that color; otherwise emit 0.

This is equivalent to inverting the generator's "paint each 3x3 output cell as a 2x2 block, then translate it into the dominant-color grid" encoding.

Generator-specific lower-cost form:

- The rare-row/column indices are arithmetic: `start + step * [0,1,2,3]`.
- `step` is recovered from background count: 400→3, 441→4, 576→5.
- The 3x3 output is determined by only eight lattice intersections:
  corners `(0,0),(0,3),(3,0),(3,3)` and middle block `(1,1),(1,2),(2,1),(2,2)`.
- Corners emit when their sampled value is not dominant. Edges emit when the corresponding middle pair matches and is not dominant. Center is always 0.

## Algorithm sketch

```
counts10     = ReduceSum(input, axes=[0,2,3])
dom          = 1 + ArgMax(counts10[1:10])
dom_ch       = Equal([0..9], dom)
rare_ch      = nonbg_ch - dom_ch
row_present  = Greater(Einsum(input, rare_ch, "bchw,c->h"), 0)
col_present  = Greater(Einsum(input, rare_ch, "bchw,c->w"), 0)
ridx/cidx    = TopK(Where(present, [30..1], 0), k=4, sorted=1)
row_sel      = OneHot(ridx, depth=30)
col_sel      = OneHot(cidx, depth=30)
sample4x4    = Einsum(input, row_sel, col_sel, [0..9], "bchw,rh,sw,c->rs")
label3x3     = Where(2D 2x2 windows are uniform rare colors, window color, 0)
output       = Equal(label3x3, [0..9]) padded to [1,10,30,30]
```
