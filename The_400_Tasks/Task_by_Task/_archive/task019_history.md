## Rule

Tile the active input grid 2x2. Preserve the nonzero marker color(s). For active background cells in the tiled 2x2 canvas, paint color 8 when the cell is diagonally adjacent to any nonzero marker cell; leave other active background cells as 0. The documented/visible invariant is that the marker color is not 8; visible+arc-gen inputs use colors `[0,1,2,3,4,5,6,7,9]`.

Reference: `Research_Archive/notes/recipe-task019-tile-with-marked-empties.md`; numpy reference: `The_400_Tasks/Task_by_Task/task019/prototypes/task019_numpy_reference.py`.

## Algorithm sketch

```python
base = np.tile(input_grid, (2, 2))
out = base.copy()
for each cell (r, c) where base[r, c] == 0:
    if any diagonal neighbor of (r, c) is nonzero:
        out[r, c] = 8
return out
```

The current public-positive ONNX family computes the live input H/W from active rows/cols, gathers rows/cols modulo H/W into a 12x12 tiled canvas, convolves the non-background mask with a 3x3 diagonal kernel, then materializes channels 0/1..7/8/9.
