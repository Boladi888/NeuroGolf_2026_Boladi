## Cost analysis

LIVE structure (39 nodes, 9 inits): per-channel pair detection via `nonbg = Slice(input16, [1:10])`, then 4 CumSum (w_fwd/w_rev along axis=3, h_fwd/h_rev along axis=2) yielding "between" booleans, gated by `row_multi`/`col_multi` (Greater(count, 1)), combined with vertical-precedence (`no_vertical = Not(OR over 9 channels of v_span_bool)` via Split + 8 Or), then cast to F32 lines, gated by `background_bool = And(valid_bool, Not(Greater(nonzero_sum, 0)))`, and Concat back to output. The valid gate exists solely to suppress ch0 in out-of-shape cells under the official zero-pad encoder.

Measured per-component cost contributions (mutate LIVE, score with `tools/_score_v2`):
- LIVE                                          cost 242829
- drop `valid_count` + `valid_bool` + And      cost 239229 (Δ -3600, +0.0149 pts) — **unsafe**, breaks 238/265 official under official validator
- drop `row_count` + `row_multi_bool` + And    cost 233919 (Δ -8910, +0.0374 pts) — safe (matches LIVE on contract; singleton-divergent off-contract)
- drop `col_count` + `col_multi_bool` + And    cost 233919 (same shape as row_multi)  — adversarial-unsafe (suppresses non-aligned spurious lines)
- drop row + drop col, keep valid              cost 225009 (Δ -17820, +0.0758 pts) — fails 29/1000 adversarial
- drop row + drop valid                        cost 230319 (Δ -12510, +0.0529 pts) — **PUBLIC-NEGATIVE -12.60** (this is `task092_drop_h_gate_drop_valid_t_d0667ade`)
- drop row + F16 `nonbg_lines_float`/bg_float  cost 232117 (Δ -10712, +0.0451 pts) — safe but below floor
- drop row + F16 lines/bg + **F16 model output** cost 214117 (Δ -28712, +0.1258 pts) — safe, above floor, `task092_drop_row_f16out_t_766d0c36`

The big lever in the 2026-05-18 worker-7 candidate is the **model output dtype**: `g.output[0].type.tensor_type.elem_type = FLOAT16` removes both the final `Cast(output_f16, F32) → output` node and the now-replaced 18000-byte F16 intermediate (the Concat output becomes the model output, which the scorer excludes from `memory`). The official `run_network` does `(out > 0.0).astype(float)`, so F16 {0.0, 1.0} produces an identical {0, 1} mask — verified 265/265 under official `convert_to_numpy` mode.

The valid gate cannot be removed without a structurally equivalent out-of-shape suppression mechanism; none has been demonstrated. drop_row_f16out is the safe ceiling for single-entry task092 shrink as of 2026-05-18.
